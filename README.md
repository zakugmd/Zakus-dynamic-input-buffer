# Zakus Predictive Buffer

this mod is too overpowered. join discord [discord.gg/zakugd](https://discord.gg/zakugd)

Geode mod for Geometry Dash 2.2081 - works on **PC (Windows)** and **Android**.

## Install
1. Download **[zakus.predictive-buffer.geode](https://github.com/zakugmd/Zakus-dynamic-input-buffer/raw/main/zakus.predictive-buffer.geode)**.
2. Put it in your `geode/mods` folder.
3. Restart Geometry Dash.

After that it updates itself: when a new version is out it downloads in the background - just restart the game and it says *"Zakus Predictive Buffer updated to vX"*.
